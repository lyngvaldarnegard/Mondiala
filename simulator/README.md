# The society simulator

A Primer-style society simulator in one self-contained HTML file: blobs gather,
trade and organise under different economic systems, political systems and laws,
so the outcomes of each combination can be compared. No build step — open
[`index.html`](index.html) in any browser, or run it from the
[Mondiala front page](../).

This is the sandbox companion to the [policy manifesto](../policy/): the
manifesto argues its rules from the top down, the simulator lets you test
similar rules from the bottom up — tax sliders, common-pile shares, parties and
elections included.

Source of truth and version history: the
[politics-economics-sim repository](https://github.com/lyngvaldarnegard/politics-economics-sim);
this copy is the build shipped with Mondiala.
